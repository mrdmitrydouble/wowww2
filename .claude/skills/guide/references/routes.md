# Маршруты, время, выдача

## Ссылки (проверенные форматы)

**Google Maps — маршрут** (официальный формат URL):
```
https://www.google.com/maps/dir/?api=1&origin=<A>&destination=<Z>&waypoints=<B>%7C<C>%7C<D>&travelmode=walking
```
- Точка — `lat,lon` (надёжнее всего) или название с городом (`Patan+Durbar+Square,+Lalitpur`). Можно добавить `origin_place_id` / `destination_place_id` / `waypoint_place_ids`, если знаешь place_id.
- `travelmode`: `walking`, `driving`, `transit`, `bicycling`.
- **Не больше 3 промежуточных точек в одной ссылке** — мобильный браузер больше не принимает (приложение и десктоп — до 9). Длинный маршрут режь на части: конец части N = начало части N+1.
- Длина URL ≤ 2048 символов.

**Google Maps — одна точка** (проверить часы/отзывы в один тап):
```
https://www.google.com/maps/search/?api=1&query=<Название+район+город>
```

**Apple Maps** (iPhone, iOS 18.4+) — несколько точек повтором `waypoint`:
```
https://maps.apple.com/directions?source=<A>&destination=<Z>&waypoint=<B>&waypoint=<C>&mode=walking
```

**Organic Maps** (офлайн, OSM) — карта с несколькими точками:
```
om://map?v=1&ll=<lat>,<lon>&n=<Имя>&ll=<lat>,<lon>&n=<Имя>
```

**Длинные/многодневные планы** — KML или CSV (название, широта, долгота, описание, день) для импорта в Google My Maps (до 5 МБ) или Organic Maps: каждый день — свой слой/цвет.

В Claude Code ссылки и реальное пешее время по OSM считает `python3 guide/tools/geo.py links|walk …`.

## Арифметика времени

- Город: ~4 км/ч; старые кварталы, рынки, фото — ~3 км/ч; ступени и подъёмы — считай отдельно (≈ 10–15 мин на каждые 100 м набора для обычного темпа; на высоте выше 3000 м медленнее).
- Время внутри точки: храм/двор/вид 15–30 мин; музей 60–120 мин; еда 45–75 мин; кофе 20–30 мин.
- Транспорт: такси/райдшеринг — добавь ожидание 5–15 мин и пробки в часы пик; общественный — интервалы.
- Итог × 1,2–1,3 запаса. Сверь с закатом (`weather` в geo.py или поиск «sunset <город> <дата>»), часами закрытия и следующим делом в календаре.
- Пиши расчёт коротко: «≈2,5 км пешком (40 мин) + 3 точки по ~25 мин + кофе = ~2 ч 15 мин, с запасом 2 ч 45 мин → выходи до 14:30, чтобы успеть на закат в 17:15».

## Формат одного варианта (текст)

```
🎯 <Название> — <чем это тебе, 1 строка, с отсылкой к эталону>
   <как добраться, сколько идти/ехать> · <сколько там быть> · <до скольки открыто / лучшее время> · ✅/⚠️
   <ссылка>
```

## События в Google Календаре (только после «да»)

Шаблон, который хорошо работает на телефоне:
- **Название**: глагол + место + суть: «Выезд на Сваямбху (лестница ×2 на закате)».
- **Начало** — время выхода из дома, а не прихода; **конец** — реальное возвращение.
- **Место** — точный адрес/название точки старта, чтобы календарь сам предложил дорогу.
- **Описание**: 2–4 строки сути (что взять, темп, закат во столько-то, где поесть) + ссылка маршрута (Google Maps `dir/?api=1…`) + ссылка на артефакт-план, если он есть.
- **Напоминания**: накануне вечером (собрать вещи/лечь вовремя) и за 30–60 мин до выхода.
- После визита (с согласия) — дописать в описание `Итог: ★N · …`.

## Артефакт-план (для поездки или насыщенной недели)

Интерактивная страница, которой удобно пользоваться с телефона:
- Карточка **«Сегодня»** сверху: что, когда выходить, ссылка маршрута, запасной вариант.
- Сетка дней с типом нагрузки/насыщенности.
- Карточка дня: суть, логистика, ссылки, «что взять», фото места (если можно).
- Кнопка **«Сделано»** и быстрая **оценка 1–5 + слово** — это и есть журнал (если у артефакта есть хранилище данных, используй его; отметки можно разделить между спутниками).
- Блок **«Если — то»**: дождь, закрыто, нет сил, болит колено — и что делать.
- Мобильная вёрстка, тёмная тема, крупные кнопки. Внешние картинки и тайлы карт в артефактах могут блокироваться — не делай карту обязательной частью; ссылки на Google/Apple/Organic Maps работают всегда.

## Офлайн-пакет (перед треком/зоной без связи)

За день до выезда предложи:
1. Скачать офлайн-карту региона в Organic Maps (или Maps.me / офлайн-область Google Maps) и отметить точки (`om://map…`).
2. Сохранить план дня/маршрута текстом в заметки или скриншотом (артефакты и ссылки без сети не откроются).
3. Ключевое офлайн: высоты/расстояния по дням, где вода/еда, точки разворота, номера экстренных служб и страховки, наличные.
