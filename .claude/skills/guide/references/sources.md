# Где искать глубже Google Maps

Проверено исследованием в ноябре 2026. «Открывается» значит, что веб-фетч Claude получает содержимое. В приложении Claude открывает только адреса, которые уже появились в разговоре: в поиске, в сообщении человека или на открытой странице. Поэтому в приложении сначала ищи, потом открывай найденное. В Claude Code можно открывать любые URL.

## Общий порядок

1. **Свежие живые сообщества**: публичные Telegram-каналы и чаты города (`t.me/s/<канал>`), Reddit через поиск (страницы reddit.com напрямую закрыты, берём сниппеты и зеркала), местные медиа и блоги. Ориентир — последние 6–12 месяцев.
2. **Местная платформа страны**: см. таблицу ниже.
3. **Wikivoyage**: открывается полностью, у пунктов есть даты обновления. Хороший каркас по районам, логистике и ценам.
4. **Подключённые коннекторы**: AllTrails (тропы), Tripadvisor, Viator, Booking. Это один из источников, а не истина.
5. **Открытые данные** (OSM, Википедия рядом, погода и закат) — из Claude Code через `guide/tools/geo.py` или через свой коннектор.
6. **Русскоязычные гиды**: Tripster открывается, у него есть экскурсии «нетуристический …» с отзывами. Это хороший источник идей маршрутов, даже если не бронировать.

Понижай в весе: подборки «10 hidden gems» без дат и деталей, агрегаторы «Reddit-backed», сайты-фермы с общими словами. Признаки слабого источника: нет цен, дат, имён людей, фото с места и конкретики «зайти со двора, спросить X».

Где местная платформа нечитаема (Корея, Китай), скажи об этом прямо. Логистику бери из Wikivoyage и OSM, места — из сниппетов поиска.

## Шаблоны запросов

- Сообщества: `<город/район> <тема> reddit <год>`, `"<район>" recommendations reddit`, `<город> underrated reddit`.
- Telegram: найди каналы запросом `site:t.me <город> <тема>` или `<город> телеграм канал куда сходить`, потом открой `https://t.me/s/<имя_канала>`. Там последние посты с временем, но без полных дат: свежесть оценивай по контексту.
- Местный язык: `<ключевые слова на языке страны> <район> <год>`, например `kuliner enak Ubud warung lokal 2026`.
- Русский: `<город> куда сходить не туристическое <год>`, `<город> что посоветуете <тема>`.
- События на неделе: `<город> events this week <месяц год>`, `site:allevents.in <город>`, `<город> афиша site:t.me`; для России `site:afisha.ru <город>`. Ночная жизнь: `"ra.co" <город>`, читай только сниппеты, сам сайт закрыт. Праздники: местный календарь, для Непала — Непал Самбат, Тихар, Дашайн и другие.
- Природа и тропы: коннектор AllTrails, `<место> trail report <месяц год>`, местные треккинг-агентства, Wikivoyage itineraries, погода на высоте.
- Свежесть и закрытия: `"<название>" <город> closed`, `"<название>" <месяц год>`, отзывы в Google Maps с сортировкой «Новые» (это делает человек по ссылке).

## Проверка, что место работает

Одного бесплатного источника нет. Комбинируй:
1. свежие упоминания: дата поста или треда, отзывы за последние месяцы;
2. платформу с живым статусом, где она есть: Wongnai, 2GIS, Tabelog;
3. открытые данные как подсказку, а не гарантию (у OSM часто нет часов работы и даты проверки);
4. ссылку `google.com/maps/search/?api=1&query=…`, чтобы человек проверил часы в один тап.

Для многодневного плана полезен второй взгляд: попроси человека прогнать план через бесплатный Gemini, у которого есть данные Google Maps, с вопросом «что из этого закрыто или неверно по часам?».
