# AI Agent

Проект для экспериментов с оркестрацией действий и памятью в стиле ИИ‑агентов.

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните переменные.
2. Установите зависимости: `make dev`.
3. Запустите анализ задач: `make triage`. Отчёт появится в `docs/triage/D-YYYY-MM-DD.md`.

## Гид: персональный ИИ-гид в Claude

Система для приложения Claude: прогулки, маршруты, «куда сейчас», поездки, новое в своём городе. Настройка и шпаргалка — [`guide/README.md`](guide/README.md). Исследование — [`reports/`](reports/).
