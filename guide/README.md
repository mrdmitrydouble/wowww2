# Гид: персональный ИИ-гид в Claude

Система, которая превращает приложение Claude на телефоне в личного гида: что делать «здесь и сейчас», прогулки и маршруты, поездки на несколько дней, новое в своём городе. Гид задаёт минимум вопросов, помнит вкус, ищет глубже Google Maps, проверяет места и даёт ссылки, по которым можно сразу идти.

Основано на исследовании (ноябрь 2026): [`reports/Персональный ИИ гид в Claude.md`](../reports/Персональный%20ИИ%20гид%20в%20Claude.md), заметки — в [`research_notes/`](../research_notes/).

## Как устроено

Прирост качества дают правила, профиль, журнал и проверка, а не сложная оболочка. Поэтому ядро — обычный Проект в приложении. Остальное — необязательные надстройки.

| Слой | Что | Где | Нужно? |
|---|---|---|---|
| 0. Настройки | геолокация, память, веб-поиск, выполнение кода, коннекторы | приложение Claude | да, 5 мин |
| 1. **Ядро — Проект «Гид»** | инструкции + профиль + справочники | Проекты в Claude | **да, 10 мин** |
| 2. Профиль и журнал | «Гид · Профиль» (Google Doc), память проекта, `places.md` | Google Drive + память | да (профиль уже создан) |
| 3. Skill `guide` | те же правила в любом чате и в Claude Code | Customize → Skills | по желанию |
| 4. Claude Code + этот репозиторий | бесплатные гео-инструменты, KML, глубокий поиск для поездок | вкладка Code | по желанию |
| 5. Свой коннектор (MCP на бесплатном Cloudflare) | журнал с записью голосом + OSM/погода прямо в приложении | — | следующий шаг, если ядро зайдёт |

Единый источник правды для правил — [`project/INSTRUCTIONS.md`](project/INSTRUCTIONS.md). Skill собирается из него командой `python3 guide/build.py`.

**Личные данные в этот репозиторий не кладём: он публичный.** Заполненный профиль живёт в приватном Google Doc «Гид · Профиль».

## Настройка с телефона (≈15 минут)

### 0. Настройки приложения Claude
1. Разрешите приложению доступ к **геолокации** (настройки телефона → Claude → Геопозиция → «При использовании»).
2. В Claude: Settings → включите **Memory** (и поиск по прошлым чатам), **веб-поиск**, **Code execution / Create and edit files**.
3. Settings → Connectors: подключите **Google Drive**, **Google Calendar**. Из каталога бесплатно: **AllTrails** (тропы), **Tripadvisor**, **Viator**, по желанию **Booking.com**.
4. Голос: проверьте, говорит ли голосовой режим по-русски. Если нет — диктуйте по-русски, ответы читайте текстом.

### 1. Проект «Гид» — ядро
Создать Проект надёжнее на claude.ai в браузере, дальше всё работает с телефона.
1. **Projects → New project** → название «Гид».
2. **Instructions**: скопируйте весь текст [`project/INSTRUCTIONS.md`](project/INSTRUCTIONS.md) (кнопка Raw → выделить всё).
3. **Project knowledge** → добавьте:
   - Google Doc **«Гид · Профиль»** из Drive (уже создан и заполнен из Календаря, Plaud и выгрузки прошлых чатов — поправьте неверное);
   - Google Doc **«Гид · Журнал мест»** из Drive (места, где уже были, с оценками — чтобы не повторять);
   - из [`.claude/skills/guide/references/`](../.claude/skills/guide/references/): `sources.md`, `routes.md`, `memory.md`, `trip-planning.md`.
4. Все разговоры «куда пойти / маршрут / поездка» ведите **внутри этого Проекта**.

### 2. Skill (по желанию)
Нужен, чтобы те же правила работали в обычном чате вне Проекта и в Claude Code.
1. Скачайте [`dist/guide-skill.zip`](dist/guide-skill.zip).
2. claude.ai → **Customize → Skills → Upload skill** → выберите zip.
3. Проверка: в новом чате вне Проекта напишите «я в центре, есть час — куда пойти?». Должна прийти подборка из трёх вариантов с метками ✅/⚠️.

### 3. Claude Code (по желанию, для поездок)
Во вкладке **Code** приложения откройте этот репозиторий. Skill `guide` подхватится сам. Плюс бесплатные инструменты без ключей:
```bash
python3 guide/tools/geo.py weather 27.67 85.32              # погода, осадки по часам, восход/закат
python3 guide/tools/geo.py nearby 27.67 85.32 --kind view,sight --radius 1500   # места рядом из OSM
python3 guide/tools/geo.py wiki 27.67 85.32                 # что рядом в Википедии (ru, en)
python3 guide/tools/geo.py walk "lat,lon@A" "lat,lon@B" "lat,lon@C"   # реальное пешее время
python3 guide/tools/geo.py links "A, город" "B, город" "C, город"      # Google/Apple/Organic Maps
```
Из облачной сессии часть сервисов (Overpass, Википедия) режет трафик. Тогда скрипт печатает готовый URL, а Claude открывает его веб-фетчем.

## Как пользоваться — шпаргалка фраз

| Хочу | Скажите |
|---|---|
| Совет на ходу | «Я тут, есть 2 часа, устал» / «куда сейчас?» (геолокация подхватится) |
| Не знаю, чего хочу | «Не знаю, чего хочу — предложи» |
| Прогулка или день | «Прогулка на полдня по старому городу, к закату» |
| Поездка | «Спланируй 5 дней в …» — будет короткое интервью |
| Новое дома | «Что нового в городе на этих выходных?» |
| Больше неочевидного | «Без классики» / «как местные» / «удиви» |
| Только главное | «Покажи главное, я тут впервые» |
| Оценить место | «Сходили в X — ★4, понравилось …, но …» |
| Запомнить вкус | «Запомни: я вообще не люблю …» |
| Обновить профиль | «Обнови профиль» → новая версия «Гид · Профиль (дата)» в Drive |
| Свести журнал | «Сведи журнал в places.md» → загрузить файл в знания Проекта |
| Закрепить план | «Поставь в календарь со ссылками маршрута» |
| Офлайн | «Собери офлайн-пакет на завтра» |

**Ритуалы (по 1–2 минуты):** после визита — оценка одним сообщением; раз в неделю — «сведи журнал»; в конце поездки — «обнови профиль».

## Импорт опыта из прошлых чатов
Запустите в приложении Claude промпт из [`prompts/import-history.md`](prompts/import-history.md) и вставьте результат в Проект: «добавь это в профиль».

## Проверить в первую неделю
1. Видит ли гид геолокацию и рисует ли карту (в Непале и Индонезии, с VPN и без).
2. Голосовой режим внутри Проекта: видит ли он инструкции, профиль и геолокацию; говорит ли по-русски.
3. Срабатывает ли Skill в мобильном чате.
4. Записывает ли Claude в память Проекта по фразе «запомни …» и может ли перечислить все записи «Журнал:».
5. Открываются ли ссылки Google Maps с 4+ точками в приложении Google Maps и работают ли `om://` для Organic Maps.
6. Держатся ли правила в длинном чате (вопросы ≤1, три варианта, строка «проверено»).

**Как понять, что стало лучше:** держите 12 постоянных запросов (по 3 на сценарий) и раз в пару недель прогоняйте их в обычном чате и в Проекте. Считайте: сколько вопросов задано, сколько мест реально работает (проверьте 3 случайных), сколько повторов, открылись ли ссылки, приняли ли вы неочевидный вариант. Надстройку оставляйте, только если она двигает хотя бы один из этих показателей.
